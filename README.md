# React Image Search

A responsive image search application built with React.js and the Unsplash API.

## Features

- Search for images using the Unsplash API
- Display search results in a responsive image grid
- Loading spinner while images are being fetched
- Hover effect to display image details
- View photographer information
- Previous and Next pagination
- Search using the Enter key
- Responsive design for desktop, tablet, and mobile devices
- Error handling for failed API requests

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Unsplash API
